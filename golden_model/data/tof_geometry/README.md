# ToF zone geometry

`tof_zone_tables.npz` gives, for each of the 64 VL53L5CX zones and each of 32 distance bins, the rectangle the
zone covers on the 80×60 label grid (the camera and ToF sensor are offset, so the footprint depends on distance).
Generated by [`hw/tools/gen_zone_tables.py`](../../../hw/tools/gen_zone_tables.py); the same tables are in the
FPGA ROM (`hw/mem/zone_*.mem`).
