# Memory images

`$readmemh` files read by the RTL (ROM contents) and by the testbenches (stimulus and expected output).
Regenerated by [`../scripts/prepare.ps1`](../scripts/prepare.ps1).

| File | Used by | Content |
|---|---|---|
| `unet_weights.mem` | `unet_core` weight ROM | 128 int8 weights per word, packed by `tools/unet_pack.py` |
| `unet_params.mem` | `unet_core` parameter ROM | Bias, multiplier, shift per output channel |
| `unet_inlut.mem` | `unet_engine` | Input quantisation LUT (pixel → int8) |
| `zone_rects.mem`, `zone_binlo.mem`, `zone_rz.mem` | `postproc` | ToF zone footprints per distance bin |
| `zone_tables.npz` | `tools/` | Same tables in NumPy form |
| `tb_frame.mem`, `tb_labels.mem` | `tb_unet_core` | Test frame and expected label map |
| `tb_pp*_lab.mem`, `tb_pp*_tof.mem`, `tb_pp*_exp.mem`, `tb_pp_ncases.mem` | `tb_postproc` | 6 post-processing cases |
| `tb_cam*.mem`, `tb_tof*.mem`, `tb_uart*.mem`, `tb_uart_len.mem` | `tb_nexys4_top` | SPI stimulus and expected UART bytes |
| `tb_imu_*.mem` | `tb_imu_packer` | IMU samples and expected packets |
