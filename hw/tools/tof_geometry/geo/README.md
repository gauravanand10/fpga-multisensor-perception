# Geometry modules

| Module | Purpose |
|---|---|
| `tof_zones.py` | VL53L5CX 8×8 zone directions and orientation |
| `calibration.py` | Camera intrinsics, camera–ToF extrinsics and orientation, with validation |
| `quick_calib.py` | Calibration without a chessboard, from clicked samples |
| `projection.py` | Zone → 3-D point → camera pixel |
| `depth_map.py` | Sparse and dense depth images in the camera view |
| `frames.py` | Data containers with timestamps |
| `config.py` | Shared settings |
