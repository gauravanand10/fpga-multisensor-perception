# Constraints

`nexys4_ddr.xdc`: 100 MHz clock (E3), Pmod pins JA (camera SPI), JB (ToF SPI), JC (IMU SPI), JD1 (servo PWM),
USB-UART TX (D4), switches, LEDs, LVCMOS33 I/O standards, false paths on the asynchronous inputs, configuration voltage
and bitstream compression. Pin table: [`../README.md`](../README.md).
